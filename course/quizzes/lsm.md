# Quiz: What Seccomp, AppArmor, and SELinux Actually Do
## Questions
1. Which control is most specific to syscall filtering?
   A) AppArmor B) SELinux C) seccomp D) cgroups
2. AppArmor primarily confines by:
   A) Image digest B) Path-based profiles C) Cloud IAM D) Overlay2 compression
3. `--security-opt seccomp=unconfined`:
   A) Tightens the default profile B) Disables the runtime seccomp filter C) Enables SELinux D) Sets memory limits
## Answers
1. C 2. B 3. B
