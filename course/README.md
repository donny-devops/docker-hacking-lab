# Course catalog

Hands-on Docker Hacking — 11 modules and 22 assessments.

Each module follows the same shape:

1. Attack scenario (what goes wrong)
2. Noncompliant example (teaching anti-pattern)
3. Compliant example (secure default)
4. Remediation
5. Hands-on lab (inspect, compare, harden)

Quizzes live in `course/quizzes/`. Module 01 (privileged containers) is required — see GitHub issue #7.

Run `make test` to confirm the catalog is complete and assessments are unique.
