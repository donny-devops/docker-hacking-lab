# Support

This project is an educational lab, not a production product.

- **Issues:** https://github.com/donny-devops/docker-hacking-lab/issues
- **Security reports:** see `SECURITY.md` (email, not public exploit details)
- **Docs:** `README.md`, `lab/README.md`, `course/README.md`, `solutions/README.md`

Before opening a bug, run:

```bash
python3 -m pip install -r requirements-dev.txt
make test
```

Include the `make test` output and your Docker / OS versions.
