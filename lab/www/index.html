Docker Hacking Lab

Isolated lab only. This service is an intentional teaching target. Do not expose it to the internet.

Use the course catalog in course/modules/ and the defensive checks in solutions/.

  • Insecure baseline: docker compose up -d
  • Switch stacks: docker compose down -v then docker compose -f docker-compose.hardened.yml up -d
  • Hardened teardown: docker compose -f docker-compose.hardened.yml down -v
  • Validation: make test
